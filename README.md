# Aiteen

Aiteen es un compañero digital con memoria diseñado para ayudar a las personas a aprender, crecer, reflexionar y alcanzar sus objetivos.

## Fundador

Carlos de Jesús Melendes Garces

## Funciones

- Chat Inteligente
- Memoria Personal
- Diario
- Metas y Tareas
- Reflexión Guiada
- Perfil de Usuario

## Visión

Crear un asistente personal capaz de recordar, acompañar y evolucionar junto a cada usuario.
